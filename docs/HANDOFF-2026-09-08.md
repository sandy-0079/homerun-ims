## 6. If something is wrong

**The code is provably inert with the flags absent** — `0 of 18,046 cells` differing, four separate
gates. So a bad night is far more likely to be data than code.

- **Wrong policy values in the master?** Fix Zoho and let the next night's sync re-assert. Do not
  hand-write `team_data/global`.
- **DC floors gone?** The Google Sheet lost its `DC Min`/`DC Max` columns. Restore them; 04:35 fixes
  itself the next night.
- **Real rollback:** `git revert 57c346c..6c977e3` + push, then redeploy the three functions **by
  name**. The catalogue is backed up at **`team_data/catalogue_backup_20260907`** (2,573 skuMaster +
  2,185 priceData, byte-verified) — restore by read-merge-write of those two keys, **never a partial
  PATCH**.
- ⚠ Reverting leaves `purchase`/`move` sitting harmlessly in `skuMaster`; the old engine ignores them.
  But `newSKUQty[sku].DC` would become an **unread key**, and the old `isFlooredSKU` is
  presence-based, so nothing breaks — the DC floors simply stop applying.
